Get 120 Hz in Safari

Safari holds web pages to 60 frames a second, even on a 120 Hz screen. Chrome doesn't. You can lift that in Safari's settings.

  1. Safari → Settings → Advanced, tick Show features for web developers.
  2. Open the new Feature Flags tab, search 60fps, and untick Prefer Page Rendering Updates near 60fps.
  3. Quit Safari, reopen it and come back.
  1. Settings → Apps → Safari → Advanced → Feature Flags, turn off Prefer Page Rendering Updates near 60fps.
  2. Settings → Accessibility → Motion, turn off Limit Frame Rate.
  3. Swipe Safari closed, reopen it and come back.
